</div>

## Features

- Multiple AI providers with custom API endpoints
- OpenAI Codex, Gemini, and Grok OAuth integrations
- DeepSeek and OpenRouter support
- Image and video generation
- Multimodal input, including images and documents
- Markdown rendering with code highlighting, tables, LaTeX, and Mermaid
- MCP and Skills support
- Web access and workspace tools
- Custom HTTP headers and request bodies

## Development

RikkaDev is developed using Kotlin and Jetpack Compose and can be opened with [Android Studio](https://developer.android.com/studio).

A `google-services.json` file may be required in the `app` directory to build the project.
